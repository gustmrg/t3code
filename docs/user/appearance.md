# Appearance

Choose **Gusty Code** in Settings → Appearance for the Midnight, Blue and Cyan palette. Use light or dark mode, follow the system appearance, or choose a different theme for each mode. The same appearance settings apply in the browser and desktop app.

Gusty Code replaces T3 Chat in the theme list. Previously saved T3 Chat selections now use Gusty Code; saved dark-mode selections remain dark. Custom themes and other built-in themes remain available.

**T3 Code** keeps its original light and dark palettes and remains the default theme. Gusty Code is a separate option; selecting it does not replace the T3 Code palette.

The environment is always identified by a pill next to the application name. Background artwork and the environment-identification selector have been removed, including the artwork option in the theme editor. Previously saved artwork or hidden-identification preferences no longer change this behavior.
